# 🦉 OwO Bot Clone by Codez

A powerful Discord economy and adventure bot inspired by OwO Bot, developed by Codez.

## Features

* 🏹 Hunting System
* 💰 Economy System
* 🎁 Daily Rewards
* 🎒 Inventory Management
* 🛒 Shop System
* 🐾 Pet Collection
* ⚔️ Battle System
* 🏆 Leaderboards
* 📊 User Profiles
* 🚀 Slash Commands
* 🍃 MongoDB Support

## Installation

```bash
git clone https://github.com/devxxz/OWO-BOT-CLONE.git
cd OWO-BOT-CLONE
npm install
```

fill  `.env` file:

```env
TOKEN=YOUR_BOT_TOKEN
MONGO_URI=YOUR_MONGODB_URI
CLIENT_ID=YOUR_CLIENT_ID
```

Start the bot:

```bash
node index.js
```

## Commands

* `/hunt` - Hunt animals
* `/daily` - Claim daily rewards
* `/balance` - Check balance
* `/inventory` - View inventory
* `/shop` - Browse shop
* `/buy` - Purchase items
* `/battle` - Fight other players
* `/profile` - View profile

## Tech Stack

* Node.js
* Discord.js v14
* MongoDB
* Mongoose
